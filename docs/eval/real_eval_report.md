## 关键发现（比结果更有价值）

1. **细粒度分块导致"一条知识横跨多块"**：标题感知分块后每"条"独立成块，一条完整知识（如"互斥锁方案"）被拆进相邻 3 块。首轮评测 2 个 MISS 全是标注粒度问题——答案的主体块其实都进了 Top5，标注却选了中间块。修正标注后 28/28。
   **方法论结论**：细粒度分块下，标注必须选"答案主体块"；更严谨的评判标准是"命中块包含答案要素"而非"命中指定块"。
2. **长文档摘要生成是串行瓶颈**：习题集 .doc 标题极多（每标题一个父块 → 一次 LLM 摘要调用），串行生成数小时未完成。**优化方向：摘要批量生成（单次 LLM 调用输出多个摘要）或并行化 + 超时快速降级**（代码已支持单块失败跳过，但串行等待拖垮了整体）。
3. **真实 PDF 页码噪音**：PDF 抽取时页码数字"1"被识别为块标题（chunk 1 的 heading_path = "1"）——真实语料的常态，不影响检索，但提示：生产环境可在解析后加页码清洗正则。

## 局限

- .doc 老格式文档因处理超时未纳入（Tika 解析本身正常，卡在摘要串行生成）
